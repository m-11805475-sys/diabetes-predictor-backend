Model setup

The notebook cleans duplicate rows, imputes missing values, and trains a CatBoost classifier with 400 maximum iterations, depth 6, learning rate 0.1, early stopping, and random seed 42.

  • Training: 48,339 records (70%)
  • Validation: 10,359 records (15%)
  • Test: 10,359 records (15%)

Important limitation

The dataset is a balanced 50/50 sample, so the model’s raw scores should not be interpreted as real-world population risk. The notebook reports performance but does not save/export the fitted model artifact.

To enable genuine model inference, export the fitted CatBoost model (for example, as a .cbm file) and connect it to a backend prediction endpoint using the exact training feature order and preprocessing.
